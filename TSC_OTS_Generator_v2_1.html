2. Import “TSC View My Classes with Registrations”

Pasting the TSC text is recommended because it is faster and more reliable than OCR. Re-pasting an updated schedule replaces only previously imported course rows. Manually entered office hours, student-support hours, and other activities are preserved.

Screenshot OCR is an optional fallback. The screenshot is processed locally in your browser and is not uploaded to this generator. OCR is less reliable than pasted text, so review the recognized schedule before relying on the OTS. The OCR engine and English language data are loaded from public CDNs when OCR is first used, so this feature requires an internet connection unless those libraries are separately bundled.

Lecture defaults to 3 administrative contact hours per week, and Lab defaults to 2. The hours printed beside each scheduled block are the weekly contact hours divided by the number of meetings that week: for example, a 3-contact-hour MWF lecture shows 1.00 beside each meeting, a 3-contact-hour TR lecture shows 1.50 beside each meeting, and a 2-contact-hour lab meeting once per week shows 2.00. Student Support is handled as clock time rather than course contact hours, with a default weekly target of 10 hours. If support hours use the same time on several days, enter them as one repeated activity; if the times differ by day, use the support-hours setup to create separate day entries. Campus / Other also defaults to actual scheduled clock time. Use Weekly Hrs Override for exceptions. Extra Teaching Assignments appear on the OTS but do not count toward the contract total.

4. Save, share, and export

Project JSON preserves the editable schedule and can be reopened in this page later. Excel creates a true XLSX with a 5-minute underlying grid, merged event blocks, a Schedule Data sheet, optional schedule-background shading, and one-page print settings. PDF draws the OTS directly in letter-page format using the same shading setting. Print / Save PDF is an offline fallback configured for one-page Letter output with printed background colors.

The page itself is a single static HTML file and does not send schedule data to a server. Direct XLSX/PDF export loads ExcelJS/jsPDF from public CDNs when needed. Screenshot OCR loads Tesseract.js and English OCR data from public CDNs when OCR is used; the image itself is processed locally in the browser. The preview, pasted-text parser, project saving, and browser printing work without those libraries.

Generator Settings

Contract and contact-hour defaults

These are weekly administrative/contract values. Lecture and Lab hours are divided across their weekly meetings when the Hrs value is printed beside each block. Student Support uses scheduled clock time and is compared with its weekly target.

OTS schedule display

Background shading is independent of the visible day range. Choose Shade outside selected hours to gray rows before the first time and at/after the second time.

Activity editor

Grouped layout creates separate Lecture, Lab, Student Support, and Campus / Other tables while keeping the same underlying schedule data.

Live preview

These preferences are saved with the browser project and in Project JSON files. Hiding the preview does not affect Excel or PDF exports.
